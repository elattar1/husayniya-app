# 🏙️ خدمات الحسينية — Husayniya Services Platform

تطبيق وموقع خدمات الحسينية الشامل للمطاعم، التوصيل السريع، الصيدليات، الدليل الطبي، والعقارات.
مصمم بنمط **Liquid Glassmorphism** فائق العصرية ويدعم العمل كتطبيق **Progressive Web App (PWA)** جاهز للتثبيت والتحويل إلى **APK**.

---

## 🌟 الميزات والشاشات:
- 🏠 **الرئيسية (`index.html`):** تصفح المتاجر، الأقسام، وبحث فوري ذكي.
- 🍖 **قائمة المطعم (`husayniya-store.html`):** تخصيص الوجبات والإضافات وسلة عائمة.
- 🛒 **السلة والدفع (`husayniya-checkout.html`):** خريطة GPS تفاعلية، طرق دفع متعددة (كاش، زين كاش)، وكوبونات خصم.
- 🛵 **تتبع الطلب الحي (`husayniya-tracking.html`):** خريطة مسار حي مع دراجة نارية متحركة ومحادثة فورية مع الكابتن.
- 🔐 **تسجيل الدخول (`husayniya-login.html`):** مصادقة رقم الهاتف مع محاكي رمز OTP.
- 📊 **لوحة الإدارة (`husayniya-dashboard.html`):** رسوم بيانية تفاعلية Canvas ومتابعة السائقين والمبيعات.
- 👤 **الحساب والمحفظة (`husayniya-account.html`):** سجل الطلبات، العناوين المحفوظة، ورصيد المحفظة.

---

## 🚀 النشر على GitHub Pages:
1. ارفع المشروع إلى مستودع (Repository) جديد على حسابك في GitHub.
2. اذهب إلى **Settings** > **Pages**.
3. في قسم **Branch** اختر `main` أو `master` ثم اضغط **Save**.
4. سيصبح موقعك متاحاً أونلاين على الرابط: `https://<your-username>.github.io/<repo-name>/`.
