# 🌿 أرياف - ARYAF — منصة الخدمات وتوصيل الريف والمراكز الذكية

تطبيق وموقع **أرياف - ARYAF** الشامل للمطاعم، التوصيل السريع، الصيدليات، الدليل الطبي، العقارات، والأمانات.
مصمم بنمط **Liquid Glassmorphism** فائق العصرية بألوان الهوية الرسمية (Deep Navy, Mint, Warm Orange, Cloud White) ويدعم العمل كتطبيق **Progressive Web App (PWA)** جاهز للتثبيت والتحويل إلى **APK**.

---

## 🌟 الميزات والشاشات:
- 🌿 **الرئيسية (`index.html`):** تصفح المتاجر، الأقسام، وبحث فوري ذكي، وهوية أرياف الذكية.
- 🍖 **قائمة المطاعم والمتاجر (`husayniya-store.html`):** تخصيص الوجبات والإضافات وسلة عائمة.
- 🛒 **السلة والدفع (`husayniya-checkout.html`):** خريطة GPS تفاعلية، طرق دفع متعددة، وكوبونات خصم.
- 🛵 **تتبع الطلب الحي (`husayniya-tracking.html`):** خريطة مسار حي مع دراجة نارية متحركة ومحادثة فورية مع الكابتن.
- 🔐 **تسجيل الدخول (`husayniya-login.html`):** تسجيل دخول جوجل السحابي وOTP.
- 📊 **لوحة الإدارة (`husayniya-dashboard.html`):** رسوم بيانية تفاعلية ومتابعة السائقين والطلبات ومزامنة سحابية.
- 👤 **حساب المستخدم (`husayniya-account.html`):** إدارة الملف الشخصي، العناوين المحفوظة، وسجل الطلبات.
- 🩺 **عيادات أرياف (`husayniya-medical.html`):** دليل الأطباء وحجز المواعيد.
- 💊 **صيدلية أرياف (`husayniya-pharmacy.html`):** روشتات وطلب الأدوية.
- 🏢 **عقارات أرياف (`husayniya-realestate.html`):** شقق ومحلات للبيع والإيجار.
- 📦 **أمانات أرياف (`husayniya-lost.html`):** المفقودات والمعثورات.
